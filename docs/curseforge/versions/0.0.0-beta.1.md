<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Ascendant Attributes for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). Same attribute library and API as the 26.2 build.</p>

<h3>About this build</h3>
<ul>
<li><strong>Re-fork, not a back-port</strong>: rebuilt from the upstream <a href="https://www.curseforge.com/minecraft/mc-mods/apothic-attributes">Apothic Attributes</a> 1.21 sources (2.10.1, Shadows_of_Fire / Stormraven Studios, MIT), rebranded to the Ascendant Attributes identity.</li>
<li><strong>Feature parity with 26.2</strong>: 20 custom attributes, 7 status effects, the Shift-to-inspect attribute GUI, EvalEx-driven configurable combat formulas, Regalia Slots API (Curios) compatibility.</li>
<li><strong>Dependencies</strong>: Common Toolkit (required, our fork of Placebo), Regalia Slots API (optional, our fork of Curios API). EvalEx is bundled (jar-in-jar).</li>
</ul>

<h3>Notes</h3>
<blockquote>Ascendant Attributes is a library. It adds no content on its own &mdash; install it as a dependency of another mod that requires it, on both client and server. MIT licensed (upstream copyright kept in <code>LICENSE</code>).</blockquote>
