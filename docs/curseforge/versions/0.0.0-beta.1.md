<h2>v0.0.0-beta.1 - Initial scaffold</h2>

<p>First public release. This is a project scaffold — no gameplay features are implemented yet.</p>

<h3>Notes</h3>
<ul>
<li>Project scaffold for <strong>Ascendant Attributes</strong>, a port of <a href="https://www.curseforge.com/minecraft/mc-mods/apothic-attributes">Apothic Attributes</a> by Shadows_of_Fire.</li>
<li>Depends on <strong>Common Toolkit</strong> (required, fork of Placebo).</li>
<li>Optional compatibility with <strong>Curios API Updated</strong> (fork of Curios API).</li>
<li>No affix/attribute gameplay code has been ported yet — see the mod's roadmap for the planned phases.</li>
</ul>
