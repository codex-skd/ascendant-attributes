<h2>v1.0.0 - First Stable Release</h2>

<p>Ascendant Attributes graduates from beta to a stable <strong>1.0.0</strong> release. The full port from Apothic Attributes is complete and verified.</p>

<h3>Features</h3>
<ul>
<li><strong>20 custom attributes</strong>: Draw Speed, Crit Chance, Crit Damage, Cold Damage, Fire Damage, Life Steal, Current HP Damage, Overheal, Arrow Damage, Arrow Velocity, Experience Gained, Healing Received, Armor Pierce, Armor Shred, Projectile Damage, Protection Pierce, Protection Shred, Dodge Chance, Elytra Flight, Creative Flight, Cooldown Reduction.</li>
<li><strong>7 status effects</strong>: Ancient Knowledge, Bursting Vitality, Grievous Wounds, Flying, Sundering, Bleeding, Flaming Detonation.</li>
<li><strong>Attribute inspection GUI</strong>: hold Shift to see a full breakdown of base value, min/max, modifiers, and formula for every attribute.</li>
<li><strong>Configurable combat formulas</strong> via a bundled expression evaluator — server owners can retune balance without recompiling.</li>
<li><strong>Curios API</strong> compatibility (optional): attribute modifiers on Curios-slotted items are recognized by combat logic and the GUI.</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Missing Spanish translation</strong>: <code>lang/es_es.json</code> did not exist — only <code>en_us.json</code> was shipped. Under a Spanish game locale, custom attribute descriptions, GUI text, status effects, death messages, and custom potion names all fell back to English. Added the full Spanish translation (130 keys).</li>
</ul>
