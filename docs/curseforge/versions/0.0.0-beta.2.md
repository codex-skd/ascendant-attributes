<h2>v0.0.0-beta.2 - Client Crash Fix</h2>

<p>Fixes a critical client-side crash on startup.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Client crash</strong>: <code>AscendantAttributesClient</code> had <code>@EventBusSubscriber</code> annotation but no <code>@SubscribeEvent</code> methods, causing mod loading to fail with <code>IllegalArgumentException</code>.</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Removed unused <code>@EventBusSubscriber</code> from client entry class — event handling is registered via NeoForge bus elsewhere.</li>
</ul>
