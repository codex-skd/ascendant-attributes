<h2>v0.0.0-beta.2 - Core port complete</h2>

<p>The first functional release. Everything in Apothic Attributes 3.0.1 has been ported: this is no longer an empty scaffold.</p>

<h3>Added</h3>
<ul>
<li><strong>Attributes</strong>: 20 custom attributes (crit chance/damage, life steal, dodge chance, armor pierce/shred, protection pierce/shred, arrow damage/velocity, cooldown reduction, and more), synced and visible in the in-game attributes overlay.</li>
<li><strong>Mob effects</strong>: Bleeding, Detonation, Flying, Grievous Wounds, Ancient Knowledge, Sundering, Bursting Vitality — each with its own icon and combat logic (auxiliary fire/cold damage, current-HP damage, dodge, critical strikes, sweep-attack tracking, and more).</li>
<li><strong>GUI</strong>: attributes overlay on the inventory screen, effect/potion tooltips, configurable HUD button position.</li>
<li><strong>Combat rules</strong>: configurable protection/armor damage-reduction formulas (via a real math-expression evaluator, not hardcoded).</li>
<li><strong>Brewing</strong>: 37 new potion mixes for the custom effects above.</li>
<li><strong>Admin command</strong>: <code>/ascattr add_bonus_modifier</code> to add a temporary attribute modifier to the held item.</li>
<li><strong>Curios API Updated compatibility</strong> (optional): attribute modifiers on items in accessory slots are recognized.</li>
<li>Original art for every icon, GUI texture and sound effect.</li>
</ul>

<h3>Requirements</h3>
<ul>
<li><strong>Common Toolkit</strong> — required.</li>
<li><strong>Curios API Updated</strong> — optional.</li>
</ul>
