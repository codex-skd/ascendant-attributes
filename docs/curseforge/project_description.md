<h1 align="center">Ascendant Attributes</h1>

<p align="center"><strong>20 custom attributes, 7 status effects, and a full in-game inspection GUI for Minecraft 26.2.</strong></p>

<br>

---

<br>

<h2>✨ Overview</h2>

<p>Ascendant Attributes is a library mod for Minecraft 26.2 (NeoForge) that adds a rich set of custom player attributes and status effects, along with a GUI to inspect exactly how each attribute's final value is built up from base value, modifiers, and formulas. It is designed as a foundation other mods (and modpacks) can build affixes, equipment bonuses, and combat mechanics on top of.</p>

<blockquote>This mod is a port of <a href="https://www.curseforge.com/minecraft/mc-mods/apothic-attributes"><strong>Apothic Attributes</strong></a> by <em>Shadows_of_Fire</em>, ported from NeoForge 26.1.2 to NeoForge 26.2. Not affiliated with or endorsed by the original author.</blockquote>

<br>

<h2>⚔️ Attributes</h2>

<p>20 custom attributes covering offense, defense, and utility:</p>

<ul>
<li><strong>Offense</strong>: Crit Chance, Crit Damage, Cold Damage, Fire Damage, Life Steal, Current HP Damage, Arrow Damage, Arrow Velocity, Draw Speed, Projectile Damage, Armor Pierce, Armor Shred, Protection Pierce, Protection Shred.</li>
<li><strong>Defense &amp; Utility</strong>: Overheal, Dodge Chance, Healing Received, Experience Gained, Elytra Flight, Creative Flight, Cooldown Reduction.</li>
</ul>

<br>

<h2>💫 Status Effects</h2>

<p>7 custom status effects tied into the attribute system: Ancient Knowledge, Bursting Vitality, Grievous Wounds, Flying, Sundering, Bleeding, and Flaming Detonation.</p>

<br>

<h2>🖥️ Attribute GUI</h2>

<p>Hold Shift while viewing your attributes to see a full breakdown per attribute — base value, minimum/maximum, and every modifier applied (flat addition, multiply base, multiply total), plus the formula used to combine them.</p>

<br>

<h2>🔧 Configurable Combat Formulas</h2>

<p>Combat math (crit damage, life steal, armor/protection pierce and shred, and more) is driven by expressions evaluated at runtime via a bundled expression engine, so server owners can retune balance without a recompile.</p>

<br>

<h2>🧩 Curios Compatibility</h2>

<p>When <a href="https://www.curseforge.com/minecraft/mc-mods/curios-api-updated">Curios API Updated</a> is installed, attribute modifiers on items equipped in Curios slots are recognized by both the combat logic and the attribute GUI.</p>

<br>
